# Icons of Gentleface

`clipboard-data.svg` is the «clipboard-data» icon of Gentleface (style line-round, the 16 px
drawing), downloaded unchanged from https://gentleface.com/svg/line-round/16/clipboard-data.svg
(page: https://gentleface.com/icons/clipboard-data). The customer chose it for the menu item
«Productivity» (decision of 16.11.2026).

`LICENSE.txt` is the license of the set (MIT), downloaded from https://gentleface.com/LICENSE.txt.
It covers the animated icons in `../motion` too.
