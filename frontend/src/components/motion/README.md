# Animated icons

`wallet-fill.svg` is the animated «wallet» icon of Gentleface, downloaded unchanged from
https://gentleface.com/motion/wallet-fill.svg (page: https://gentleface.com/icons/wallet).
The site states the icons are MIT licensed.

`settings-ratchet.svg` is the animated «settings» icon of Gentleface, downloaded unchanged from
https://gentleface.com/motion/settings-ratchet.svg (page: https://gentleface.com/icons/settings).
The customer chose it for the menu item «Settings» (decision of 16.11.2026). The part worth
playing once is 0.25–2.1 s, as the page of the icon says.

The license of the set is in `../gentleface/LICENSE.txt`.
